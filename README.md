# 青毡

原创的娱乐向无限制德州扑克。中文界面，只有游戏筹码，没有充值、提现或现金兑换。

一桌六人桌，盲注 50 / 100。新注册玩家钱包里有 10,000 筹码。桌上坐着三位牌友，一个人也可以打完一整手。中途断开后，用同一账号重新连接，会回到原来的座位。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
npm install
npm start
```

浏览器打开 http://localhost:3000 。

```bash
npm test
```

账号保存在本机 `data/qingzhan.db`。

## 规则

标准无限注德州扑克：每人两张底牌，翻牌三张、转牌一张、河牌一张，用其中最大的五张比牌。可以弃牌、过牌、跟注、加注或全下。加注至少要达到最小加注；筹码不够时可以不足额全下。多人全下时，边池分开结算。平分时的零头筹码，从按钮左侧的玩家开始分配。
